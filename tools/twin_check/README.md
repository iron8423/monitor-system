# twin_check —— 控制点验证（复查清单 P1-9）

「模型和现实对得上吗」在这套系统里此前只能靠眼看。这个工具把它变成一个可以复现的数字：
输入一组**实测控制点**（RTK / 全站仪 / 已知坐标点），输出每个点的残差与整组的 RMS。

## 它算的是什么

| 量 | 定义 | 说明什么 |
|---|---|---|
| **ΔE / ΔN** | 实测经纬度换算到本地 ENU 后，减去资产里同编号测点的声明位置 | **配准**误差：锚点、投影常数、资产里声明的点位对不对 |
| **ΔZ** | 实测高程 − 模型地面高程（基准面 + 该点处的高程场采样） | **高程**误差：公开 30m DEM 与实测地面的差，也就是「拿模型做高程判断」的误差上界 |
| RMS / 均值 / 最大值 | 上述三组的统计量 | 均值同向且量级接近 → 锚点整体偏了，工具直接给出锚点该改成多少 |

高程场用的是**后端做遮挡判断时的那一份**（`backend/src/main/resources/terrain/<资产版本>.bin`），
读取时校验 SHA-256——校核的就是平台实际在用的模型，不是另算一遍出来的第二份。
网格还没导出时（例如新资产刚生成），加 `--sources` 从 DEM 素材按同一套参数重建。

## 用法

```bash
# 自检：用一组已知偏移（3.0m 东 / -1.5m 北 / +0.8m 高程）的合成点验证这套数学
python3 tools/twin_check/check_control_points.py --self-test

# 用仓库里的示例控制点（就是资产声明的 7 个点，残差应当只有毫米级）
python3 tools/twin_check/check_control_points.py \
    --asset frontend/public/models/qingyuan-hillside-v2 \
    --points tools/twin_check/samples/control-points-hillside.csv \
    --out docs/samples/twin-check-hillside.md

# 换成现场实测：同表头写一份 CSV 即可（列顺序任意，多余列忽略）
#   code,longitude,latitude,altitude,note
python3 tools/twin_check/check_control_points.py --points /path/to/rtk.csv --tol-height 0.8
```

其他场景换 `--asset frontend/public/models/qingyuan-bridge`（或 railway / factory）即可，
高程场按资产版本自动选。

常用参数：

- `--tol-plane`（默认 0.10m）/ `--tol-height`（默认 0.50m）：判据。平面 0.1m 是雷达形变监测的
  合理要求；高程 0.5m 是 30m DEM 在缓坡上的典型水平，换成航测 DSM 应收紧到 0.05m。
- `--json <文件>`：机器可读结果，给流水线用。
- `--assert-rms <m>`：平面 RMS 超阈值就以退出码 1 结束。

退出码：`0` 通过 / `1` 有超阈值的点 / `2` 输入或环境问题。

## 怎么读结果

- **控制点太少（<3）时均值没有统计意义**，只看逐点值与最大值。
- **高程残差不为零是正常的**：这份地形是公开 30m DEM + 程序化细节，陡坡上米级偏差属于
  数据本身的分辨率，不代表模型不合用。它的用途是给出误差上界。
- **残差同向才是信号**：所有点都往东偏 2m，那是锚点问题；东一个西一个，那是测量噪声或
  点位没对上。
- 改锚点等于**重新配准**：已生效的雷达标定会全部失效（位姿与视线的几何前提变了）。
  工具给出的建议值只是「如果你确信实测」，改之前先想清楚这一点。

## 示例输出（节选）

```
| 点号   | 声明位置 (E,N)      | 实测位置 (E,N)      | ΔE     | ΔN     | 模型地面 Z | 实测 Z  | ΔZ     |
| P-HK01 | -150.000, 200.000   | -150.005, 200.001   | -0.005 | +0.001 | 211.385    | 211.384 | -0.001 |
...
| 平面 RMS | 0.0052 m |
| 高程 RMS | 0.0011 m |
```

那 5mm 的平面残差不是「模型不准」，而是**经纬度只存到 7 位小数**带来的往返换算误差——
换成实测数据时它会被真实误差盖住，但知道这个底噪有用：小于 1cm 的残差不用追。
