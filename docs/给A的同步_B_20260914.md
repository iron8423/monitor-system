## 3. 需要你动手 / 知情的四件事

### 3.1 SSE 不按订阅者过滤（你日志 §120）——根治在你

项目隔离把 `/points`、`/devices` 限到了「成员项目」，但 SSE 仍推全库。两边叠在一起，
会出现「界面上看不到这个点，告警却推到了这个浏览器」。

B 在前端做了临时收口（`monitor.applyAlarm`）：POINT 告警的 `pointId` 必须在本页已加载的
测点里；DEVICE 告警的 `deviceId` 必须在 `/devices` 可见集合里。**但这只是不外溢到界面**，
别的项目的 `pointCode` / `deviceCode` 仍会到达不该看到的浏览器 —— 服务端按订阅者过滤才是根治。

### 3.2 `ProjectSummaryService.maxDeformation` 写死 `defo_mm`

测项中立化之后，前端可以切主测项、也可以加新测项，但项目概览的「最大形变」仍只认 `defo_mm`。
两条路你选一条：按测项档案/规则口径化，或在契约里写明「概览只统计形变测项」。
**我没动**（属你的 telemetry 范围），列为待办。
