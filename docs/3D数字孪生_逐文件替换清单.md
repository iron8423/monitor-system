## 四、什么情况下还需要上一轮山地文件

如果目标机器已经出现用户截图中的山体、雷达扇区和 7 个测点，则不需要重复替换上一轮文件。
如果目标机器仍是旧的全球 Cesium 页面，才需要同时补上一轮的 `V9__mountain_demo_scene.sql`、
`frontend/public/models/mountain-demo/`、`frontend/src/cesium/createViewer.js` 与原山地基础文件。

## 五、替换后最短验证

```bash
cd frontend && npm ci && npm run build
cd ../backend && ./mvnw test
cd ..
docker compose --env-file .env.production -f docker-compose.production.yml up -d --build
docker compose --env-file .env.production -f docker-compose.production.yml ps
```

随后严格按《3D数字孪生_生产候选部署与验收》第 6、7 节导入测试档案、回放数据和验收。
