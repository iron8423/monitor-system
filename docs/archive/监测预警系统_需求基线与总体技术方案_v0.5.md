> 用途：给老师、项目的人看，用大白话讲清楚“这套系统是干嘛的、给谁用、初版做成什么样、后面怎么扩展”。
> 依据：以**最新调研文档**为主线（通用多传感监测管理系统，落点=清远电厂“天地一体化”，第一批真接=毫米波点形变雷达）。《清远电厂软件系统框架搭建说明书》只是技术参考，不是主线。
> 本稿按**老师/负责人最新口径**更新：先出一个初版、初版**只接雷达**、**3D 数字孪生大屏必须做出来**（达到参考链接/样图那种效果）、无人机影像接入挂点、报警联动采集**只留接口**、整体**功能界面向华测对齐**、初版**本地运行**、**场景已定 = 清远电厂灰库/库区边坡地灾点形变监测**。

## 一、这套系统是干嘛的（一句话）

公司做雷达和各种传感器，装在铁路、边坡、矿山、电厂这些地方，盯着**变形、位移、水位、结构安全**。

这套系统把这些设备报上来的数据**统一收进来**，在一个**3D 数字孪生大屏**上看：真实三维地形上把每个监测点标出来、看数值/曲线、有没有告警、处理情况。系统要做**通用**——换地方、加传感器不用重做。

- 第一个落地项目：**清远电厂“天地一体化”监测预警系统**。
- 初版真实接入：**公司的毫米波点形变雷达**（先只做雷达）。
- 初版场景（已定）：**清远电厂灰库/库区边坡 地灾点形变监测**。

## 二、为什么需要它（痛点 + 价值）

| 现在的问题 | 这套系统带来什么 |
|---|---|
| 靠人工巡检：贵、做不到 24 小时、发现晚 | 自动盯着，24 小时不间断 |
| 出了事才发现，损失大 | 提前预警，防患于未然 |
| 现场数据分散，看不到全貌 | 3D 一张图看全部点位 |
| 报警处理没留痕 | 处理过程全程记录，追得回来 |

价值一句话：**事前预警、避免事故、省钱、支撑决策。**

## 三、谁来用（角色）

| 角色 | 关心什么 | 能做什么 |
|---|---|---|
| 领导 / 访客 | 总体态势、趋势、大屏 | 只能看，不能改 |
| 值班监测员 | 实时数据、有没有告警 | 看实时、确认警情 |
| 专业研判员 | 曲线、照片、报表、现场 | 判断真假、建议升级/解除 |
| 运维人员 | 设备掉线、没电、数据异常 | 处理设备、做维护记录 |
| 项目管理员 | 某个项目/区域的配置 | 建点位、配点数、配报警值 |
| 系统管理员 | 账号、权限、系统设置 | 管人、管权限、管系统 |
| 设备 / 现场盒子 | 上报数据、接收下调指令 | 自动上传、偶尔听平台指挥 |

> **没授权的人看不到没被授权的项目**；改关键配置要留痕。

## 四、初版做成什么样（重点：3D 驾驶舱）

初版的“样子”参考老师给的两条链接和样图：**一套科技感 3D 数字孪生监测大屏**，界面布局对齐华测，内里逻辑我们自己定。

**大屏布局（照这张图的样子来）**：

| 位置 | 内容 |
|---|---|
| 顶部 | 系统标题 + 右上角日期时间 |
| 左上面板 | **监测点列表**：每个点状态、最新值、是否告警（红色高亮） |
| 左中面板 | **测点形变数据**：柱状/指标卡（累计变形、速率等） |
| 左下面板 | **历史数据 / 报警时段**：时间轴 + 曲线，可按日期筛选 |
| 中央（核心） | **真实 3D 地形场景**：山体、水面、厂区，上面**标注所有监测点**（带标签，按状态变色），可旋转/缩放/平移 |
| 底部 | 一排**导航页签**：现场总览、边坡/大坝安全、设备工况、质量评估等 |
| 整体 | 深色科技风 + 青色高亮，像参考那样有“科技感” |

**3D 是必须项，不是加分项**：中央这一块要做到“像参考链接/样图一样”的真实三维场景 + 监测点标注 + 流畅浏览。这是初版的门面，也是验收重点。

## 五、系统要做哪些事（功能）

### 1. 把数据接进来
- **雷达数据**（初版核心）：目标 `seq/angle/distance/signal/state/累计变形` 等。
- **无人机影像**：航拍照片/视频接入，挂到监测点上（3D 里能看现场），跟样图那种“先看点位再看现场”一致。

### 2. 把东西管起来
- 项目、区域、监测点、设备（型号/编号/装哪儿/什么协议/标定）。

### 3. 标进 3D 场景（重点）
- 每个监测点在地图/3D 地形上算出真实位置，标出来。
- **点一个点**：最新值、历史曲线、照片、告警，全部弹出。

### 4. 看数据
- 实时 + 历史曲线（累计变形、变形速率）；按项目/点/时间查；导出表格。

### 5. 预警 + 处理
- 超阈值自动弹告警；确认 → 研判 → 处置 → 解除，每步留痕；不重复刷屏，级别高能升级。
- **报警联动加密采集：初版只把接口/字段留好**（先不做真实联动，后面接上）。

### 6. 设备运维
- 掉线、没电、数据中断/异常 → 能发现、提醒、记录处理。

### 7. 系统管理
- 账号、角色、权限；点位/报警值/参数；审计留痕；按天/周/月/年出报表。

### 8. 扩展（以后）
- 加其他传感器、加铁路/大坝/其他电厂，不改主框架就能接。

## 六、这套系统的“不一样”在哪（差异化 + 难点）

1. **3D 数字孪生监测大屏**——真实三维地形 + 监测点标注 + 流畅交互，像参考那个效果（初版门面）。
2. **坐标 / 标定可切换**——换边坡/铁路/大坝，坐标体系能切（最难、最值钱）。
3. **多传感器统一模型**——雷达/水位/GNSS/影像先统一成“设备 → 监测点 → 时序 → 告警”，前端一套逻辑。
4. **无人机影像挂点**——空中看现场，点开一个点看履历。
5. **功能界面像华测，内里可不同**——用户看到/操作的布局、交互对标华测；内部算法、存储、扩展按我们自己的来。

> ⚠️ 能力边界：公司雷达是**点形变**（测**单个点**的累计变形 + 地图标一个点），**不是**整片云图/热力图（那是 GB-InSAR）。要跟甲方讲明白，别误会。

## 七、初版范围（已确认）

**能做**：
- 3D 数字孪生大屏（必须，达到参考效果）。
- 雷达数据接入 → 标点到 3D → 实时/历史曲线 → 告警 → 处理留痕，闭环跑通。
- 无人机影像接入、挂点到监测点、3D 里看现场。
- 报警联动加密采集：**只留接口**。
- 功能界面布局向华测对齐。
- 初版本地运行，能演示。

**初版不做**（以后再加）：
- 水位计、位移计、GNSS、测斜等其他传感器（先只雷达）。
- 无人机飞控/自动建模/多期三维变化对比（先只接影像挂点）。
- 相机视觉识别、多租户、移动端、机器学习趋势预测、行业标准对接。

## 八、初版成功长什么样（验收）

1. **3D 大屏能跑起来**：真实地形 + 监测点标注 + 左右面板 + 底部页签，效果像参考那样。
2. 雷达连续上报，平台识别设备、落库、在 3D 上标出监测点。
3. 点一个监测点：最新值、累计变形+速率曲线、影像/照片、告警全出来。
4. 超阈值自动告警，不重复刷屏，确认—研判—处置—解除全程留痕。
5. 界面布局/交互跟华测“神似”，内里是我们自己的实现。
6. 初版本地就能跑，给老师演示“点开一个点看全”的 3D 闭环。

## 九、风险：要趁早想清楚

| 风险 | 影响 | 怎么避免 |
|---|---|---|
| **3D 效果做不出来/卡顿** | 初版门面失败 | 先拿免费地形 + 少量标点跑通，再优化观感 |
| **坐标/标定能不能做通用** | 决定成败、最花时间 | 先边坡跑通标定，再抽成通用 |
| **没有真实地形/影像数据** | 3D 干瘪 | 先用免费地形影像，找公司要项目区数据 |
| **范围越做越大** | 烂尾 | 初版只做“雷达 + 3D + 影像 + 告警”闭环 |
| **没拿到雷达样例数据** | 验证悬 | 用模拟数据 + 找公司要雷达样例 |

## 十二、参考（老师提供）

> 只是参考“怎么搭/做成什么样”，不是需求；技术选型后面再定。

- **仿照 1：TvT.js（three-vue-tres）**——国产化 Web 3D 数字孪生底座，Apache-2.0，自带 12 个案例（有“地图空间编辑器”贴合），适合做 3D 场景/大屏观感。
- **仿照 2：CesiumJS**——真正 GIS/地理空间 3D 引擎，能处理真实经纬度、地形、倾斜摄影、3D Tiles、时序轨迹动画、空间分析；**做“监测点标到真实地图上”更贴合**。
- **参考样图**：一套水电站/大坝类 3D 数字孪生监测大屏（顶部标题日期、左侧点位列表+形变数据+历史时段、中央真实三维地形带监测点标注、底部导航页签、深色科技风）——无人机功能“跟这个差不多”。
- **最终对齐：华测（Huace）**——测绘/监测起家，本质是“真实地理坐标 + 传感器监测”平台；我们对齐它的**功能界面/布局**（界面像、内核可不同）。
