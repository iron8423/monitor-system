# 通用多传感监测管理系统 · 需求说明（通俗版）

> 用途：给老师和项目相关的人看，用大白话讲清楚“这套系统是做什么的、给谁用、要满足哪些事”。
> 版本说明：本文按**最新调研文档**来写，主线是“**通用多传感监测管理系统**”。之前那份《清远电厂软件系统框架搭建说明书》**只是参考材料**，里面是一些能用的技术实现，**不是主线**。所以本稿**先不写技术选型**，只写需求；技术怎么搭以后再说。
> 谁要拍板、还没定的项，都标了【待定】。

---

## 一、这套系统是干嘛的（一句话）

公司做雷达和各种传感器。这些设备装在铁路、边坡、矿山、电厂这些地方，用来盯着那里的**变形、水位、位移、结构安全**。

这套系统就是把**这些设备报上来的数据统一收进来**，在电脑（网页）上看：地图上每个监测点在哪、数据是多少、有没有超限、要不要报警、报警了有没有人处理。而且这套系统要做得**通用**——换一个项目、换一种传感器都能直接用，不用重新开发一遍。

用接地气的话说：**一套“通用监测管理平台”**，给公司各种传感器用。

- 第一个真正落地的项目：**清远电厂“天地一体化”监测预警系统**。
- 第一批真正接进来的数据：**公司的毫米波点形变雷达**（后面再加水位计、位移计、GNSS、无人机照片等）。

---

## 二、为什么需要它（痛点 + 价值）

| 现在的问题 | 这套系统带来什么 |
|---|---|
| 边坡、铁路、点位变形，靠人工巡检：贵、做不到 24 小时、发现得晚 | 自动盯着，24 小时不间断 |
| 出了事才发现，损失大 | 提前预警，防患于未然 |
| 现场数据分散，不知道每个点现在什么状态 | 一张图/一个界面看全部 |
| 报警有没有人处理、怎么处理的，没留痕 | 处理过程全程记录，追得回来 |

一句话价值：**事前预警、避免事故、省钱、支撑决策。**

---

## 三、谁来用（角色）

不同人看的东西、能做的不一样：

| 角色 | 他关心什么 | 能做什么 |
|---|---|---|
| 领导 / 访客 | 总体情况、趋势、大屏 | 只能看，不能改 |
| 值班监测员 | 实时数据、有没有报警 | 看实时、收到报警、点“确认” |
| 专业研判员 | 数据曲线、照片、报表、现场情况 | 判断真假、建议升级/解除 |
| 运维人员 | 设备掉线、没电、数据不正常 | 处理设备问题、做维护记录 |
| 项目管理员 | 某个项目/区域的配置 | 建点位、配点数、配报警值 |
| 系统管理员 | 账号、权限、系统设置 | 管人、管权限、管整套系统 |
| 设备 / 现场盒子 | 上报数据、接收下调指令 | 自动上传，偶尔听平台指挥 |

> 说明：不是“登录了都能看全部”。**没授权的人看不到没被授权的项目**，改关键配置要做记录。

## 四、系统总共要干哪些事（功能清单）

### 1. 把数据接进来
- 雷达数据、其他传感器数据。
- 人工填的/导入的报表（和自动监测数据放在一起看）。
- 无人机拍的照片、现场照片。

### 2. 把东西管理起来
- 项目、区域、监测点、设备（型号/编号/装在哪儿/什么协议）。
- 每个设备装在哪、什么时候装的、标定过没有、现在好坏。

### 3. 标到地图上（重点）
- 每个监测点在地图上算出位置，2D/3D 地图上标出来。
- **点一下某个点**，能看到它最新数值、历史曲线、照片、有没有报警。

### 4. 看数据
- 实时曲线 + 历史曲线（比如累计变形、变形速率）。
- 按项目、区域、点位、时间范围查。
- 能导出来（变成表格）。

### 5. 预警 + 处理（重点）
- 数值超过设置的阈值 → 自动弹报警。
- **一个传感器超限了，可以自动让其他相关传感器加密采集、多报几次**（这条很关键，是特色）。
- 报警有人点确认 → 专业人员研判 → 派人处置 → 解除；每一步都留记录。
- 报警不重复刷屏，级别升高能升级。

### 6. 设备运维
- 设备掉线、没电、数据中断、数据异常 → 能发现、能提醒、能记录怎么处理的。

### 7. 系统管理
- 账号、角色、权限。
- 点位、报警值、参数配置。
- 改了什么要留痕（审计）。
- 出报表：按天/周/月/年一键导出。

### 8. 扩展（以后）
- 加新传感器、加新场景（铁路/矿山/其他电厂），不用改主框架就能接进来。

## 五、适用场景（为什么“通用”）

| 场景 | 坐标怎么描述 | 形态 |
|---|---|---|
| 铁路 | 里程 / 桩号（第几公里第几米）+ 哪条轨道 | 雷达、相机装在轨道旁或车上 |
| 边坡 / 矿山 | 平面坐标 + 高程（有地形起伏） | 固定、车载、便携都有 |
| 电厂（清远） | 平面坐标 + 高程；现场区域、灰库边坡、铁路专用线 | 雷达 + 传统传感器 + 无人机 |

**不同地方用的坐标不一样**，但系统要能在不同坐标之间切换，每个地方配好自己的标定，不改主程序。

---

## 六、这套系统的“不一样”在哪（差异化 + 难点）

以下几件事做好了，这套系统才有价值、也最花功夫：

1. **坐标 / 标定可切换**——换地方（铁路→边坡）系统照样用。最关键，也最花时间。
2. **多传感器统一成一套模型**——雷达出变形、水位计出水位、GNSS 出位置变化、无人机出照片，底层都先统一成“设备 → 监测点 → 时序 → 告警”，前端一套逻辑。
3. **3D/地图上点开一个监测点就能看全**——最新值 + 曲线 + 照片 + 报警。
4. **无人机照片挂到点位上**——点开能看这个点的“履历”（照片、变化过程）。
5. **超限自动联动加密采集**——一个点超了，带动相关传感器多采数据。

> ⚠️ 一个要说清楚的能力边界：公司的雷达是“**点形变**”——测**单个点**的累计变形，在地图上标一个点；**不是**“整片形成云图/热力图”（那是 GB-InSAR，属于另一种东西）。这点要跟甲方/老师讲明白，别造成误解。

## 七、第一批做到什么程度（范围：先小后大）

**先做（最小闭环）**：
接数据 → 存下来 → 处理（解析、标定、融合） → 分析（告警、趋势） → 展示（2D/3D 地图 + 大屏） + 权限 + 项目管理 + 报表。

**第一批真接的设备**（建议）：
- 毫米波点形变雷达（必须）。
- 先加 1~2 种其他传感器（比如水位计、GNSS）验证“通用”。
- 无人机照片上传、挂到点位。

**第一版就做“一个小闭环”**：点形变雷达 + 无人机照片 + 3D 图上点开看数据/曲线/照片。这一条能跑通，工作量就能控制住，不至于烂尾。

**以后再加**：更多传感器、更多场景、多租户、移动端、机器学习趋势预测、无人机自动建模型、多期三维变化对比。

---

## 八、成功长什么样（验收标准）

1. 能接进多种传感器：雷达、位移计、水位计、GNSS、相机……（至少雷达 + 1~2 种跑通）。
2. 每个监测点能标到准确空间位置：铁路用“里程/桩号”，边坡/电厂用“平面坐标 + 高程”。
3. 3D/地图上点一个监测点，能看到最新值、历史曲线、照片、报警。
4. 数据实时到位，报警值能分级、能配置。
5. **换一个地方、加一种传感器，不改主框架**就能用。

---

## 九、风险：要趁早想清楚的

| 风险 | 影响 | 怎么避免 |
|---|---|---|
| **坐标/标定能不能做通用** | 决定“通用”成不成立，最花时间 | 先拿一个场景（建议边坡）跑通标定，再抽成通用适配 |
| **多传感器数据格式不一样** | 不统一好就乱套 | 先定统一模型 + 每种设备一个“解析插件” |
| **范围越做越大** | 做不完、烂尾 | 把“最少能跑通”的先定死，别的后置 |
| **还没拿到公司其他传感器的协议/样例** | 接入层可能先空转 | 先用雷达 + 1~2 种能拿到协议的先做，别的预留 |
| **没有真实数据** | 标定、验证、模型都悬 | 先定义清楚数据格式，造模拟数据，找公司要样例 |
| **需求还没定死、后面可能来人** | 反复返工 | 先定框架 + 留一份统一文档当基线，框架可插拔，改场景成本低 |

## 十、现在还定不下来、要先问清楚的事【待定】

1. 第一个真实场景：**铁路**还是**边坡**？（建议先边坡，标定更容易跑通）
2. 第一批做到什么程度：**演示级**还是**能上线的完整版**？人力和时间？
3. 要不要**相机 / 视频 / 视觉识别**？（这条影响大）
4. 雷达之外，**先接哪 1~2 种传感器**？（水位计？GNSS？）
5. 无人机照片怎么定位：靠 EXIF 经纬度、航点，还是人工把照片挂到点上？
6. 3D 底图用**免费开放数据**（卫星/地形），还是要花几十万做**高精度三维模型**（倾斜摄影/BIM/点云）？
7. 系统装在哪：**厂内网**、公司服务器，还是**云端**？地图能不能联网加载？
8. 要不要对接**行业标准 / 监管平台**（比如广东地灾监测规范）？

---

## 十一、下一步建议

1. 先跟老师 / 负责人对齐上面 8 个【待定】，尤其先定**场景**和**第一批设备**。
2. 把这份通俗稿做成正式的《需求说明书》：每项需求有编号、优先级、谁用、做到什么程度算完成。
3. 再基于确认的需求，画数据模型、设计页面、定接口。
4. 技术选型后面再定（先把需求讲清楚，技术自然好选）。

---

> **一句话总结**：做一套**通用**的多传感监测管理系统，把公司雷达和各种传感器收进来的数据统一管理、标到 2D/3D 地图上、随时看曲线、超限自动报警并联动加密采集、处理有留痕；第一批先落地清远电厂，先接雷达 + 1~2 种传感器 + 无人机照片，把“点开一个点看全”的闭环先跑通。
