# 三维大屏 · 验收清单（2026-09-21）

> 用法：打开大屏 → 从上到下逐条点一遍（约 15 分钟）→ 每条记 **✅ / ❌ + 一句话**（❌ 的写"哪里、什么样"）。
> 把 ❌ 的编号发我就行，我按编号改。**编号后面我改进时也用它。**

## 准备

- 地址：<http://localhost:5173/screen>（未登录会先跳登录，账号 `admin` / `123456`）
- **先按一次 Ctrl+F5**（强制刷新，避免旧资产被浏览器缓存）
- 打开 DevTools（F12），右上角能看到 FPS 更好：`Ctrl+Shift+P` → 输入 `fps` → 选 "Show frames per second (FPS) meter"
- 顶栏应出现橙色小标签「试验渲染·资产覆盖」——**看不到这个标签就说明没加载到试验资产，先告诉我**

## A. 首屏与构图

| # | 怎么做 | 合格标准 | 记 |
|---|---|---|---|
| A1 | 进大屏，别动鼠标，看默认构图 | 模型占屏幕宽度 **70%~85%**，上下留一点呼吸位；不偏不切边 | |
| A2 | 看相机俯角 | 能看出地形起伏（不是垂直俯视），约 30°~45° | |
| A3 | 点左侧「回到全局视角」 | 模型**刚好填满**画面（和 A1 差不多），不是变小、也不是钻进去 | |
| A4 | 滚轮**一直往外**拉到不能拉 | 仍能看到完整模型，**不出现"模型变成一个小点"**；但边会露 | |
| A5 | 滚轮往里推到最近 | 不会穿进模型内部（不会看到背面/黑面） | |

## C. 边界与"虚空"

| # | 怎么做 | 合格标准 | 记 |
|---|---|---|---|
| C1 | 默认视角下看模型四周 | 边界不突兀（雾里淡出），**不出现"一张纸浮在黑底上"** | |
| C2 | 拉到最远（同 A4） | 能看到边，但**边上不是硬切口**（雾自然过渡） | |
| C3 | 旋转 90°，换角度看四个边 | 四个方向的边界观感一致 | |

|---|---|---|---|
