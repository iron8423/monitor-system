## 0. 2026-09-22 更新摘要

### 0.1 解决了"转到哪都看到地块边缘"这个老问题

根因不是地块不够大，而是**地块之外什么都没有**。按 -30° 俯角算，靠扩地块需要 20 km 见方才推得出画面，
纹理还会被摊薄到没意义。现在改成"让地块之外有真实地面"：

1. **远景影像层** `VITE_FARFIELD=local+ion`
   - `local`：`frontend/public/farfield/` 的 Google 瓦片金字塔（z0~z15、72×54 km、296 张约 4 MB），
     由 `tools/imagery_fetch/fetch_farfield.py` 生成，**运行期不联网**；
   - `ion`：底下垫一层 Cesium ion 影像（Bing）兜更远的地方，断网时自然缺失。
   - 为什么远景也用 Google：Bing 在本场址是**建设期旧图**（冷却塔还是脚手架）、色调偏黄
     （实测 HSV 饱和度 62.8 vs Google 27.7）。同源之后交界色差基本消失。
   - ⚠️ 瓦片模板必须写成 `/farfield/{z}/{x}_{y}.jpg`。用 Cesium 默认的 `{z}/{x}/{y}` 会**全部 404**，
     而且页面看着"还行"——因为一直由底下的兜底图层在渲染。这个坑记在这里。
2. **雾**：`density` 与 `visualDensityScalar` 要一起给才有效（公式见 `createViewer.js` 顶部注释）；
   以前只调 density，在 3~10 km 尺度上几乎没效果；另外 `applyViewerTheme` 切主题会把密度重置，**现已修**。
   当前 `VITE_FOG_DENSITY=0.0003` + `VITE_FOG_VISUAL_SCALAR=0.08`。
3. **相机**：俯仰放开到 -8°~-85°、缩放上限 ×2.5；新增 `VITE_CAMERA_FIT_MAX_RANGE=2800`
   （不再把相机推到 5 km 外）；取景与"回到全局视角"仍共用同一个函数。
4. **lit 档修隐患**：`renderProfile.js` 原来在受光模式下 `globe.show=false`，
   远景层上线后会一开就把远景藏掉、虚空回归；**现已改为保留椭球与大气**。

## 2. 怎么开关（全部走环境变量，不动数据库）

```dotenv
# frontend/.env.local（gitignore，不进库）
VITE_RENDER_MODE=flat          # flat=历史行为；lit=受光渲染
VITE_RESOLUTION_SCALE=1.5      # 画布分辨率（1.2 更省，2 最锐）
VITE_CAMERA_RANGE_SCALE=0.7    # 取景收紧；VITE_CAMERA_FIT=0 可退回固定取景
VITE_CAMERA_PITCH=-38
VITE_FOG_DENSITY=0.0011
VITE_MAX_ZOOM_DISTANCE=12000
VITE_ASSET_OVERRIDE=/models/<预览资产>/<xxx>.glb   # 临时替换场景资产（跳过哈希核对）
```

## 3. 本地预览资产：**故意没有入库**

`frontend/public/models/qingyuan-*`（wide / g19 / powerplant …）都是**本地预览**，原因有两条：

1. **许可**：它们的纹理来自 Google / 高德影像，条款禁止离线缓存与二次分发——推到共享仓库等于再分发；
2. **体积**：单个 31~33 MB，几个版本就是几百 MB，会把仓库撑坏。

预览资产只在 B 本机存在；要正式入库必须换成**天地图（授权）或购买影像**，并**走新版本号迁移 + 更新 `asset_sha256`**（不能覆盖旧资产、不能改已执行过的迁移）。

## 4. 需要你配合的三件事

1. **总平面图 / CAD / BIM**：B 侧用 0.27 m 卫星影像目视摆厂区结构体（冷却塔/烟囱/厂房），**落点始终对不齐、近看必露馅**。电厂一定有总平面图，拿到后可按**真实位置 + 真实尺寸**建；这是目前唯一能"近看也站得住"的路径（航拍暂时飞不了）。
2. **影像授权/采购**：免费源上限约 0.5 m（高德 z18）～0.27 m（Google z19，需代理）；要进交付物必须走授权。采购规格与询价单已在 B 侧整理（可另发）。
3. **资产哈希与迁移**：若要把预览版资产正式化，需要新迁移版本 + `asset_sha256`；本地当前的"资产覆盖"只是开发开关，不是交付形态。

## 5. 已知限制（如实登记）

- 受光渲染只有太阳直射、**没有环境光**，背光坡会发黑（默认已关，`VITE_RENDER_MODE=flat`）；
- 免费影像的清晰度上限：高德 z18 = 0.55 m/px（部分区域无 z19）；Google z19 = 0.27 m/px（需代理）；
- 厂房/冷却塔等结构体为**程序化示意级**，不代表工程尺寸；`ASSET_PROVENANCE.md` 里已按此口径标注；
- 新增的 GLB 工具链（改纹理、合并结构体）都会做**完整性校验**（BIN 长度 = 声明长度、bufferView 在范围内）——曾因分块长度读错产出过坏文件，现已固化为必查项。

## 6. 复现命令

```bash
# 抓高清影像（示例：全 Google，需代理）
python tools/imagery_fetch/fetch_imagery.py --source google \
  --anchor-lon 113.541523 --anchor-lat 24.4162209 \
  --width 3000 --depth 2250 --zoom 17 --out generated/imagery-<场地代号>

# 重建地形资产（默认 unlit，与历史一致）
python tools/terrain_asset/build_terrain_asset.py --scene mountain \
  --sources generated/terrain-asset/sources-<场地代号> \
  --width 3000 --depth 2250 --cells-x 750 --cells-y 562 \
  --asset-name <资产名> --out frontend/public/models/<资产名>
```
