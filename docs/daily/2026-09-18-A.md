# 工作日志 2026-09-18 · A（3D 大屏：离线真实地形资产）

> 需求（用户原话）：「图中的地形，通过卫星图片还原出来；雷达及其数据暂时使用模拟的。」
> 补充定案：「先做离线的」——运行期不请求任何在线服务，后续再接无人机航测数据。

## 一、先回答「卫星图片能不能建模」

结论与边界（9 条，详见 `docs/3D数字孪生_离线真实地形资产_20260918.md`）：

1. 单张卫星影像只有**颜色**没有**几何**：地形起伏必须来自 DEM、立体像对或无人机航测；
   影像能提供的是正射纹理。这两件事在方案里必须分开写，否则会被读成「拿张图就能生成 3D」。
2. 三条现实路线：① DEM + 正射影像贴图（本轮采用）；② 立体像对摄影测量（真重建，但
   300m 级场地性价比远低于无人机航测）；③ Google Photorealistic 3D Tiles（现成三维，
   但中国覆盖稀疏、必须联网、条款禁止离线缓存与再分发）。
3. **Google / Esri 影像不能离线下发**：两家的服务条款都禁止抓取、长期缓存与二次分发；
   Google 中国区影像还带 GCJ-02 偏移，和 WGS-84 测点叠加会整体错位。
   可离线且合法的免费高分辨率影像选择只有 Sentinel-2（10m，CC BY 4.0）。

## 二、选址：原演示坐标是平地

先下了清远周边约 12×15km 的公开地形瓦片做扫描，结果是：

- 原演示坐标 `113.0508E, 23.7208N` 的真实高程只有 **2–20m**——是平地，做不出边坡；
- 在市区以北约 4km 找到一处完整坡面：320×240m 内真实起伏约 96m、平均坡度约 15°，
  影像上有林地与一条浅色裸露带（山区道路/冲沟），适合讲「山脊 + 滑坡体」。

**这条不是「顺手换个坐标」**：测点与雷达的经纬度/高程、雷达朝向、7 条标定关系
全部要按新高程场重算，否则立柱会悬空、雷达会指着地形背面。

## 三、交付

### 1. 工具（新增 `tools/terrain_asset/`）

| 脚本 | 作用 |
|---|---|
| `fetch_sources.py` | 抓公开 DEM（Mapzen/AWS terrarium，SRTM 派生）与 Sentinel-2 cloudless 影像，带 SHA-256 缓存清单 |
| `build_terrain_asset.py` | 建高程场（DEM 骨架 + 程序化细节）→ 烘焙纹理（曝光归一 + 山体阴影 + 细节）→ 写 GLB + 元数据 + 迁移草稿 |

刻意的取舍：不直接下 SRTM `.hgt`（1° 瓦片 20MB+，实测十几 KB/s），改用 terrarium 分块
（同样覆盖几百 KB，且不需要 GDAL）；细节幅度、太阳方位等全部写进 `ASSET_PROVENANCE.md`，
分开「实测」与「程序化」。

### 2. 资产

`frontend/public/models/qingyuan-hillside/`（`qingyuan-hillside-1.0.0`）：
320×240m、38,400 三角面、内嵌 2048×1536 JPEG、`KHR_materials_unlit` + 烘焙阴影，
1.00 MiB。同一份数据源与参数重复构建得到**逐字节一致**的 GLB。

### 3. 数据与接线

- `V18__real_terrain_asset.sql`：切换默认项目资产 + 重算 7 个测点、2 台雷达的坐标/位姿 +
  重建 7 条标定（`device_point`），旧资产 `mountain-demo` 原样保留作回退；
- 测点归属按真实通视重排：北侧雷达看守山脊 3 点 + 上部滑坡体 1 点，南侧雷达看守坡脚 3 点
  （仍是 4/3 目标，与 V2 口径一致）；
- 生成器带**视线自检**：任一目标不可见（净空 ≤ 0.25m）或超出视场/量程就直接失败，
  不会产出「雷达看不见自己测点」的资产。

## 五、边界与后续

1. 30m DEM + 10m 影像 + 程序化细节只解决**观感**，不是测绘成果；
2. 接无人机航测：同一条流水线，`--detail-amplitude 0`，并把测点坐标按航测成果重算；
3. 完善清单第 36/37 条（视场按地形裁剪、自动通视计算）仍未动——本轮只把**标定关系**的
   视线算准（逐米步进），屏幕上的扇面仍是解析扇形；
4. 生产数据集 `generated/production-baseline-20260916` 的标定仍来自 `mountain-demo-2.0.0`，
   它服务的是独立测试项目 900，如要换地形需另行重采样。
