# 预览环境搭建（给 A）· 2026-09-22

> 目的：解释**为什么 `git pull` 之后看不到高清底图**，以及要看到它需要拿什么、配什么。
> 一句话：**代码在仓库里，高清底图和远景瓦片不在仓库里**（许可 + 体积），而且激活它们的 `.env.local` 也不入库。

## 1. 先分清两件事（避免误判成"代码没拉到"）

| 现象 | 是不是问题 | 原因 |
|---|---|---|
| 后端代码"还是几天前的" | **不是** | 本轮**一行后端都没改**。`backend/` 最后一次改动是 A 自己的 `897432f`（2026-09-20） |
| 看不到清远电厂那版高清底图 | **不是** | 高清底图是 Google 影像烘焙的 GLB 与瓦片，**按服务条款不得再分发**，且单个 30 MB 级，所以不入库 |

**怎么确认代码确实拉到了**（在仓库根目录跑）：

```bash
git log --oneline -3        # 应看到 b36d903 / 6fe4726 / 3d91fb1
ls docs/给A的移交_20260922.md docs/系统审计_冗余与死代码清单_20260922.md
git diff --stat 897432f..HEAD -- frontend/ tools/ docs/   # 应显示 21 files changed
```

## 2. 要看到高清底图，需要从 B 侧拿两个目录

这两个目录**不在仓库里**（`.gitignore` 明确排除），需要单独拷：

| 目录 | 大小 | 放到哪里 | 作用 |
|---|---|---|---|
| `frontend/public/models/qingyuan-powerplant-big/` | 36.8 MB | 同名路径 | 6000×4500 的清远电厂地形资产（中心 0.27 m/px） |
| `frontend/public/farfield/` | 约 4 MB | 同名路径 | 地块之外的远景瓦片金字塔（z0~z15、72×54 km） |

（可选）`qingyuan-powerplant-clean/`（30.9 MB）是 3000×2250 那一版，用来回滚对比。
历史观感试验版本已归档在 B 侧 `Desktop\实习\监测系统-archive\2026-09-22-清理\`，一般不需要。

## 3. 需要自己建 `frontend/.env.local`（不进 git）

**不配这个文件也能跑**，但看到的是数据库里登记的老场景（清远边坡 V2），不是清远电厂预览版。内容如下：

```dotenv
VITE_CESIUM_ION_TOKEN=<你自己的 ion token>   # 可用 https://ion.cesium.com/tokens 申请
VITE_TERRAIN_MODE=ion

# 指向预览资产（跳过 SHA-256 核对；正式化必须走新版本号迁移 + 更新 asset_sha256）
VITE_ASSET_OVERRIDE=/models/qingyuan-powerplant-big/qingyuan-powerplant-big.glb

# 远景层：local=本地 Google 金字塔（不联网）；+ion=再垫一层在线影像兜更远
VITE_FARFIELD=local+ion
VITE_FARFIELD_SATURATION=0.45    # 仅在远景用在线源时生效（Bing 偏黄、饱和度高一倍）
VITE_FARFIELD_BRIGHTNESS=0.97
VITE_FARFIELD_TERRAIN=0          # 打开会让真地形从地块里"冒出来"，默认关

# 雾：两个参数必须一起给，公式见 frontend/src/cesium/createViewer.js 顶部
VITE_FOG_DENSITY=0.0003
VITE_FOG_VISUAL_SCALAR=0.08

# 相机与画布
VITE_CAMERA_PITCH=-38
VITE_CAMERA_FIT_MAX_RANGE=2800   # 不把整块 6km 塞进画面（否则相机退到 5km，显小）
VITE_CAMERA_FIT_RADIUS_FACTOR=0.42
VITE_CAMERA_FIT_MARGIN=0.98
VITE_CAMERA_MIN_PITCH=-85
VITE_CAMERA_MAX_PITCH=-8
VITE_MAX_ZOOM_FACTOR=2.5
VITE_PIN_HEIGHT_M=60
VITE_RESOLUTION_SCALE=2
VITE_RENDER_MODE=flat            # lit=受光渲染（背光偏暗，需环境光，暂不推荐）
```

## 4. 启动与自检

```bash
cd backend  && ./mvnw.cmd -o spring-boot:run      # 8080
cd frontend && npm run dev                        # 5173
# 浏览器打开 http://localhost:5173/screen ，账号 admin / 123456
```

进去后按一次 **Ctrl+Shift+R**，然后核对这四点：

1. 顶栏出现橙色小标签 **「试验渲染·资产覆盖」**（说明用的是预览资产）；
2. 顶栏资产状态显示 **「预览资产」**（而不是"资产未核对"）；
3. 左下角诊断行有 `模型半径=3760(场景实测) 取景距离=2800` 这类数字（`?` 表示取景没跑起来）；
4. 转到接近水平的角度、再往外拉：**远处是真实影像一直延伸到地平线，没有"地块边缘的虚空"**。

## 5. 如果不想拷文件：自己重新生成（需要能访问对应影像源）

```bash
# 远景瓦片金字塔（Google 源需要代理；国内直连可用 --source bing，但该场址 Bing 是建设期旧图）
python tools/imagery_fetch/fetch_farfield.py \
  --anchor-lon 113.541523 --anchor-lat 24.4162209 --out frontend/public/farfield
```

地块资产（GLB）需要按 `docs/3D数字孪生_生产数据准备与上线实施指南.md` 的流水线重建：
`fetch_sources → build_terrain_asset → composite_imagery → replace_texture → validate_glb`。
**换纹理后必须跑 `validate_glb.py`**——曾因长度字段算错产出过坏文件，浏览器表现是"一直转圈不出图"。

## 6. 断网/无 token 时的降级行为

- `VITE_FARFIELD=local`：只用本地远景，**完全离线可用**（推荐给内网演示）；
- `VITE_FARFIELD=off`：退回"深色椭球 + 只有地块"，此时转到低角度会重新看到地块边缘（这是老行为）；
- 没有 ion token 时，底下的在线兜底层会加载失败，但**不影响本地远景**。
