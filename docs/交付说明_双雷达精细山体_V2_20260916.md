# 双雷达精细山体 V2 交付说明（2026-09-16）

## 交付结果

- 山体从 9,600 面升级为 38,400 面，增加复合山脊、沟谷、滑坡后缘、滑坡槽、道路与排水带；
- 演示场景从一台雷达覆盖全部点，调整为北/南两台雷达分别覆盖 4/3 个可见目标；
- 雷达目标关系增加目标号、方位、俯仰、斜距、反射器高度、LOS、净空、标定状态和有效期；
- 管理端可完成雷达位姿维护、测点绑定和标定激活；
- 3D 大屏可切换当前雷达，显示其三维视场、目标 LOS 和浮窗标定信息；
- 严格接入模式拒绝未绑定、未标定、遮挡/过期及位置偏离标定的消息；
- 7 点模拟器按两台雷达自动路由，CSV 回放默认映射同步调整；
- 全量数据集包含 10 台雷达、1000 个目标、141,625 条消息、负向契约和异常真值；
- 全量数据集中的 1000 条标定均由 V2 地形实际采样，最小 LOS 净空 0.267m。

## 升级命令

先备份现有 PostgreSQL 和媒体卷，然后在项目根目录执行：

```bash
cp .env.production.example .env.production
# 编辑 .env.production：PG_PASSWORD、JWT_SECRET、MONITOR_INGEST_KEY 必须替换
# 若 80 端口被占用，把 FRONTEND_PORT=80 改为 FRONTEND_PORT=8088 等空闲端口

docker compose --env-file .env.production \
  -f docker-compose.production.yml up -d --build
```

Flyway 会在原数据卷上自动执行 V11，无需安装宿主机 PostgreSQL，也不要删除现有数据卷。

## 生产边界

本包可以作为现场联调和试运行基线，但自带山体、经纬度、设备参数、LOS 与测值均为模拟数据。
正式生产必须用现场测绘资产重新配准并逐目标标定；模拟数据不能作为工程风险判断依据。
